# WrapDesk｜瓶标平展

WrapDesk 以罐身表面弧长为横坐标，把正面原照中的圆柱标签展成透明 PNG。原照、标定、缺证框和封存稿都在本机。

运行 `./start.sh` 并访问 [瓶标工作台](http://127.0.0.1:19901/)。环境变量 `WRAPDESK_PORT` 可设置不同本机端口。`./start.sh stop` 停止服务并保留卷。锁定依赖见 `requirements.txt`，也可直接运行 `python -B -m wrapdesk`。

1. 导入单帧 PNG、JPEG 或 TIFF，或打开带反光的合成练习。输入上限为 12 MiB、320 万像素、长边 8192 像素。
2. 点取标签上下两条边的四个端点，填写罐身直径、标签高度、希望展开的起止角和输出采样密度。以 0° 为罐子正面。应用后，工作台按实物尺寸生成正面弧段平展，输出最多 200 万像素。
3. 在原照标记反光或遮挡为缺证框，或从当前检查中移除框。平展稿用透明像素显示缺证。
4. 在平展稿点查原照像素、表面角度、距展开起点的实物弧距及色值。画一条横向测线可读实际弧长、相邻实见点之间的覆盖长度和亮度剖面。
5. 封存平展与当前测线，重新打开可核对原照，下载平展 PNG、测线 CSV 和原照 PNG。封存稿以当时的标定与缺证框为准。
6. 照片准备可裁切、校正或合成原片，应用后将已生成的结果作为新原照送入瓶标台。

坐标为 EXIF 正向后的原片像素。圆柱近似使用正视、弱透视模型。标定四角允许补偿轻微歪斜与上下两行的图像宽度差。实物直径对整张标签固定，范围限正面 ±80°。原照上的高光可手工排除。工作台保存正向 RGB PNG，不含原相机文件的二进制与元数据。
